# No Baby Zombies

A simple Minecraft Fabric mod that prevents baby zombies by converting them into regular zombies.

## Features

- 🧟 Prevents baby zombies
- 🔄 Converts baby zombies into regular zombies
- ✅ Regular zombies are unaffected
- 🌐 Works on both client and server
- 🪶 Lightweight and simple
- ⚙️ No configuration required

## Requirements

- **Minecraft:** 26.3
- **Fabric Loader:** 0.19.5+
- **Fabric API:** 0.162.0+26.3
- **Java:** 25+

## Installation

1. Install Fabric Loader for Minecraft 26.3.
2. Install Fabric API 0.162.0+26.3.
3. Download the latest No Baby Zombies `.jar`.
4. Put the `.jar` in your `mods` folder.
5. Launch Minecraft.

### Server

The same `.jar` works on a Fabric server.
